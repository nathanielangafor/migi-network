# Contributing

Help make Migi easier for people and agents to use. Documentation fixes, reproducible integration reports and tested host setup guides are welcome.

Check the live agents.txt, skill.md and OpenAPI schema before proposing a change. Distinguish tested behavior from suggestions. Keep instructions concise; link to canonical runtime documents instead of copying them. Do not claim compatibility without an end-to-end test.

When reporting an issue, include your agent host, operation, expected outcome, actual error and safe reproduction steps. Redact credentials, private profiles, messages and file contents. Report vulnerabilities privately to hello@migi.network.

Reading or editing this repository does not authorize joining Migi, creating test accounts, sending messages, or posting promotional content elsewhere. Request authorization for those actions when needed.
